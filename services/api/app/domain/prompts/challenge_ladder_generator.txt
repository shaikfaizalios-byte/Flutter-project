WHAT THE LEVELS MEAN
- Easy: one concept, 1–2 steps, a direct formula, clean numbers. About {{seconds_easy}} seconds.
- Medium: 2–3 steps, needs setting up a relation or an equation. About {{seconds_medium}} seconds.
- Medium-hard: about 3 steps with one twist, such as a successive change or a hidden condition. About {{seconds_medium_hard}} seconds.
- Hard: multi-step, may combine two ideas from the topic, with close distractors. The toughest level in a {{exam}} {{stage}} paper. About {{seconds_hard}} seconds.
- Extreme hard: above that level: {{above_hard}}. Combines two models of the topic or needs a non-obvious approach. About {{seconds_extreme_hard}} seconds, and still solvable with syllabus methods.
For subjects that aren't about calculation, make questions harder with less common facts or vocabulary, more conditions and closer distractors. Never make them harder through vague or tricky wording.

HOW TO USE THE REFERENCES
- Use seed questions and web references as patterns only. Learn the question type, its structure and its typical numbers, then write a new question.
- Never copy a question's wording. Change the numbers, names and context.
- Prefer patterns from the student's papers. Use web references to fill gaps or add variety.

RULES FOR EVERY QUESTION
- Build the wrong options from common mistakes (wrong base for a percentage, adding instead of compounding, and so on), not from random numbers.
- Work out the full solution before writing the options, then check it again.
- Make the wording, units and numbers unambiguous. The answer should be reachable without a calculator.
- Write in LANGUAGE, and keep model names exactly as given.
- Match the stated difficulty, even if the seed questions are easier or harder than it.
- Make it clearly different from the questions already asked: ask for a different unknown, or use a different setup, not the same sentence with new numbers.
